## Customising for Specific Locations

Replace the location parameter with the student's preferred area. Common patterns:

- **London:** add `&l=London` (Indeed) or `&location=London` (LinkedIn)
- **Manchester:** `&l=Manchester` or `&location=Manchester%2C%20England%2C%20United%20Kingdom`
- **Specific postcode area:** Indeed accepts UK postcodes — `&l=B1+1AA&radius=25` for 25-mile radius around that postcode
- **Multiple cities:** run separate searches and combine results in the application log

For UK-wide search (default if student has no preference), keep `United Kingdom` as the location.

## Optional Broader Queries

If main searches return little:
- "Site Engineer Graduate" — often a CM-equivalent for civils/infrastructure
- "Apprentice Construction Manager" (Level 6 degree apprenticeship) — for current students considering switching to apprenticeship route
- "Project Coordinator Construction" — entry-level office-based role, often a stepping stone to assistant CM
- "Building Surveyor Graduate" — adjacent role, transferable skills
